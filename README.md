# 生生 · 守阙人

一个用 44 张自制卡牌做成的**多支线文字冒险**（《隐形守护者》那种玩法）：卡是画面，也是剧情；抽到的卡就是读到的段落。

- 96 个剧情节点 / 8 个结局 / 44 张卡
- 单文件 HTML，无外部依赖，5.3MB，离线可跑
- 探索热点 · 抽卡 · 道具解锁支线 · 人物形态对谈 · 收集册

## 直接玩

打开 `index.html` 即可（或 GitHub Pages 首页）。

手机端建议竖屏。存档在 localStorage（`ss_profile_v1` 图鉴/结局/缝，`ss_slot_1..3` 手动档）。

## 玩法

| 系统 | 说明 |
| --- | --- |
| 文字冒险 | 序章 + 五章 + 终幕；GDI 生成度唯一数值；同一处对话不同选项会走不同结局 |
| 探索热点 | 三处场景各藏 5 个可点热点，点齐给额外 GDI + 线索；部分热点直接掉道具 |
| 抽卡 | 线索 +1 / 道具 +2 / 集齐 +3 / 结局 +15 攒「缝」；单抽 12、十连 108；十连保底史诗、同批不重复、重复折回 4 缝 |
| 道具 | 道具就是卡；持有后剧本里灰掉的选项会亮起（补完半轮太阳 / 橙灯照门缝 / 摊开纲纸指空白） |
| 展台 | 44 张卡按 角色 / 场景 / 道具 / 生生 / 幕间 筛选，卡详情 3D 倾斜 + 五种箔变体 |
| 人物对谈 | 点说话人名牌，看这个人的全部形态（道玄三态、差半四态、持阙三态…），说三句，次数存盘 |

## 8 个结局

真结局「生生」要求 GDI ≥ 0.60，且没补全差半、没给空白体命名、没接受定义。其余 7 个结局分别对应：收编、砸盒、补全、命名、交纲、焊死、关掉一切。

## 素材来源

- 一册 20 张：原《生生》卡册原画，卡面文案即剧情素材
- 二册《幕间》24 张：为这个游戏新绘（人物形态 12 / 场景 6 / 道具 6），同时补进卡组
- 剧本：由卡面 quote / bio / steps 与世界观设定改写；**原始小说正文不在手上**，所以台词是按卡面设定写的，不是小说原文摘录

## 录屏说明

画面是真实运行的逐帧截取（CDP screencast，30fps 输出）。浏览器 WebAudio 的雨声没有进音轨，视频里的环境音是按游戏内雨声参数（棕噪 + 240–1400Hz 带通 + 0.1Hz 慢波动）合成的。
